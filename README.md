# 桃溪小院 · 风动小院（0.2）

手机优先的古风卡通 3D 农场。所有项目文件、依赖与检查记录均保存在本文件夹内。

## 启动

3D 版需要通过本地网页服务器访问，请使用试玩链接，不要直接双击 HTML。

在此文件夹打开终端：

```sh
python3 server.py
```

电脑打开 http://127.0.0.1:5173/ 。手机与电脑连接同一 Wi-Fi，访问终端显示的手机地址。停止服务器按 Ctrl+C。也可运行 `npm start`。

Three.js 已安装在本文件夹的 node_modules 内；游戏不依赖外部 CDN，启动后不用联网下载角色或场景。若依赖文件被移除，可在此文件夹运行 `npm install --cache ./work/npm-cache` 恢复。

## 本次升级

- 整个场景改为真实 WebGL 3D，包括女孩、兔兔、顶橘子的卡皮巴拉、作物、庭院、拱桥、树木和石头路。
- 地图扩为 130×104 场景单位，增加外围曲径、北侧山脚路、南侧林径、听风亭、果园支路和连接桥两岸的环路。
- 菜园有 4×4 地块，花园有 2×3 地块，地块四周及地块之间都有石头小径。果树位于路旁。
- 三个角色都只沿道路中心线寻路。点击草地或作物时，角色会走到对应区域附近的道路上。女孩不能穿过菜地，兔兔跟随女孩走过的路线，不抄近路；卡皮巴拉在路网上自主游走。
- 院门双扇木门有开合动画。关闭时，路网断开；打开后，可穿门进入庭院。有人穿门时不允许把门关在角色身上。
- 桥面属于同一条路网，角色在桥上的高度跟随拱形桥面变化。
- 树冠随风摆动，作物和果树轻轻摇曳，荷塘有扩散的水纹。
- 女孩有髋部、膝部与肩部关节的步态动画；兔兔有四腿与耳朵动作及小跳；卡皮巴拉四腿交替迈步，挠痒时侧躺翻滚、闭眼、冒出爱心，再继续沿路散步。
- 为手机减少场景绘制开销：石头、树木使用实例网格，静态场景及每块地的植物按材质合并，阴影分帧更新。

## 试玩步骤

1. 拖动地图探索，点石头路走一走；双指捏合、鼠标滚轮或右侧 ＋ / − 缩放。
2. 右侧「门」按钮可以查看与开关院门。也可点击地图中的院门标记。
3. 「逛小院」里点击「打开院门，走进小院」看完整入院路线；点击「沿石头路，走过小桥」看过桥步态。
4. 用「播种」或地块上的 ＋ 管理作物。四个区域各有 3 种选择，保留原版 12 种作物、45 秒～3 分钟的周期、一次浇水、收获和集市。
5. 在「逛小院」里定位橘子君，然后点它挠痒痒。它每次重新加载都随机出现在路网的一个位置。

旧版的种子钱、库存、爱心与作物进度会保留到新版，院门状态也会保存。仍为本地单人版，每个浏览器分别保存，没有账号或跨设备同步。

## 检查

```sh
npm run check
npm test
```

`work/roads.test.js` 检查沿路寻路、院门连接、院墙不能绕过、拱桥高度和田地不能穿越。`?qa` 页面使用独立验收存档。旧版画面代码备份在 `work/game-v1.js`；旧版生成图片留在 assets 内，但新版场景不再使用图片作为地图或角色。
