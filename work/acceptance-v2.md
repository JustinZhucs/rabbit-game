# 风动小院（3D 版）验收记录

## 自动检查

- JavaScript 模块语法检查通过：game.js、scene3d.js、models.js、roads.js。
- 5 项路网测试通过：180 组路径插值始终位于可见石头路；闭门不能穿越；开门连接内院；桥两岸可连通且高度连续；点击作物投影到田间道路；院墙不存在其他路网入口。

## 实际浏览器交互

- 手机 390×844、窄屏 320×740、电脑 1280×720 可显示 3D 场景，320 窄屏无横向溢出，顶部按钮均在屏幕内。
- 庭院门双扇开启后，小桃走到内院 (-24,-22)，兔兔停在 (-24,-19.3)，两者 onRoad=true。院门状态刷新后保留。
- 过桥途中，小桃到达 (24.60,-11)，高度升至约 0.92；此时小桃、兔兔、卡皮巴拉均 onRoad=true。桥中央高度为 1.93。
- 手机端播种胡萝卜，种子钱 274→266，浇水剩余时间 45→36 秒，不能重复浇水。
- 点击 3D 卡皮巴拉触发侧躺翻滚，petting=true、moving=false、onRoad=true，使用闭眼姿态；完成后爱心 +3，随后恢复路网游走。
- 手机端收获 2 份小番茄；在小竹篮送去集市，种子钱 266→338。
- QA 使用独立存档，正式页面旧存档仍为种子钱 260、爱心 7（未被验收操作更改）。
- 最新 QA 页面无 console error / warn。正式浏览器曾保留较早的阴影类型警告，现已替换为支持的 PCFShadowMap，不再新增该警告。

## 性能处理

石头和树木采用实例绘制，静态环境与作物按材质合并，阴影间隔更新。常见观察视角的渲染调用由初稿约 2400 次下降到约 100～340 次（视野、阴影更新帧、作物数量会改变数值）。没有对真实手机设备的帧率作保证。

## 边界

本次在浏览器模拟手机尺寸与鼠标输入验收。双指触控已实现，尚未在真实手机硬件上验收。角色是程序构建的真实 3D 网格与关节层级，步态为程序动画，未使用动作捕捉。所有项目文件及依赖仍位于 Downloads/mo game。
